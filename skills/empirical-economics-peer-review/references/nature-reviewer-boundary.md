# Boundary with nature-reviewer

`empirical-economics-peer-review` is the domain reviewer for applied economics and finance. `nature-reviewer` (a separate skill, which may not be installed) remains the explicit Nature-style/general reviewer and retains its own multi-reviewer isolation and Nature-oriented framing. Do not merge reports silently. If the user names Nature, route there; if the user names enterprise finance, A-share panels, reghdfe, or econometric identification, route here.
